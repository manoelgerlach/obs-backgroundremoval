# Reporting Bugs

If you find a bug in this Windows DirectML fork, report it by
[opening a fork issue](https://github.com/manoelgerlach/obs-backgroundremoval/issues). The
[original project issue tracker](https://github.com/royshil/obs-backgroundremoval/issues) is for upstream bugs.

Please include the following information:
- Desription of the bug
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots
- OBS logs (Help -> Log Files -> Upload last log file, or by navigating to `%appdata%\obs-studio\logs`)
- Windows version and x64 architecture
- OBS version
- (If relevant) GPU: model, driver version
